# First TensorFlow Model – Learning y = 2x

## Project Overview

This project demonstrates how to train a simple neural network using TensorFlow in Google Colab to learn the mathematical relationship y = 2x.

## Objective

To train a TensorFlow model and compare predicted output values with actual output values.

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Google Colab

## Workflow

1. Create training data using y = 2x.
2. Build a simple neural network.
3. Compile and train the model.
4. Predict output values for new inputs.
5. Compare predicted and actual values.
6. Visualize the results using a graph.

## Expected Result

The trained model predicts values close to the actual values for the relationship y = 2x.

## Project File

`First_TensorFlow_Model.ipynb` – Google Colab notebook containing the code, training process, predictions, and graph.

## Conclusion

The experiment demonstrates the basic process of training a neural network with TensorFlow and evaluating its predictions.
